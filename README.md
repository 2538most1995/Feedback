# Feedback & Survey System (ระบบประเมินความพึงพอใจและออกเกียรติบัตรออนไลน์)

ระบบประเมินความพึงพอใจออนไลน์ พร้อมระบบจัดการแบบประเมิน สถิติ และการออกแบบ/ออกเกียรติบัตรออนไลน์อัตโนมัติ (PDF & PNG)

## ✨ ฟีเจอร์หลัก (Key Features)
- **ระบบทำแบบประเมิน (Survey)**: รองรับคำถามหลายรูปแบบ (มาตรประมาณค่า 5 ระดับ, ตัวเลือกเดี่ยว, หลายตัวเลือก, ดรอปดาวน์ และข้อความ) พร้อมคำอธิบายเพิ่มเติมรายคำถาม รองรับการเปิดบนมือถือและ LINE In-App Browser
- **ระบบออกเกียรติบัตรอัตโนมัติ (Certificate Generator)**:
  - ดาวน์โหลดเป็นไฟล์ PDF ขนาด A4 แนวนอน (100% Full Bleed)
  - บันทึกเป็นรูปภาพ PNG คุณภาพสูง พร้อมโหมดพรีวิวและบันทึกลงอัลบั้มมือถือ
  - รองรับการเปิดผ่านแอปพลิเคชัน LINE ได้อย่างสมบูรณ์แบบ
- **ระบบจัดการเกียรติบัตร (Certificate Designer)**:
  - ดับเบิลคลิกเพื่อพิมพ์แก้ไขข้อความได้ทันที
  - ย่อ/ขยายตัวอักษรและรูปภาพได้หลายวิธี (Floating Toolbar, จุดจับ 4 มุม, สไลเดอร์)
  - ปรับตำแหน่งและแยกลายเซ็นกับชื่อผู้ลงนามได้อย่างอิสระ
  - บันทึก โหลด แก้ไข และลบเทมเพลตที่รวมพื้นหลัง โลโก้ ลายเซ็น ข้อความ ขนาด และตำแหน่ง เพื่อนำกลับมาใช้กับแบบประเมินรอบต่อไป
- **ระบบแอดมิน (Admin Management)**: จัดการแบบประเมิน, ดูคำตอบ, สรุปสถิติและกราฟวิเคราะห์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS), FontAwesome, Chart.js, QRCode.js, html2canvas, jsPDF
- **Backend**: PHP 7.4+ / PHP 8.x
- **Database**: MySQL / MariaDB (PDO UTF-8)

## 🚀 วิธีการติดตั้ง (Installation)
1. นำโฟลเดอร์โปรเจกต์ไปวางใน Web Server เช่น MAMP, XAMPP หรือ Server (`htdocs/Feedback`)
2. นำเข้าฐานข้อมูลจากไฟล์ `database.sql`
3. ตรวจสอบการตั้งค่าฐานข้อมูลในไฟล์ `api/config.php`
4. เข้าใช้งานระบบ:
   - **หน้าทำแบบประเมิน**: `http://localhost/Feedback/`
   - **หลังบ้านผู้ดูแลระบบ**: `http://localhost/Feedback/admin/`
